# AI Job Market Analysis Dashboard

An interactive Excel dashboard that analyzes 10,000+ AI job postings to show trends in salaries, experience levels, industries and remote-work opportunities.

## About the Project
This project explores the AI job market to understand which roles are in demand, what they pay, and how much remote work is available.

## Tools Used
Microsoft Excel, Power Query, Pivot Tables

## What I Did
- Cleaned and transformed the dataset using Excel and Power Query.
- Analyzed trends in salaries, experience levels, industries and remote-work opportunities across roles.
- Built an interactive dashboard with Pivot Tables, KPIs, charts and filters.
- Highlighted high-demand AI roles and salary patterns.


## Key Insights
- The dataset covers 51,767 AI job openings, with an average salary of ₹1,13,438.
- Technology is the top hiring industry with 9,149 openings. Finance (8,654), E-commerce (8,657), Healthcare (8,466), Retail (8,440) and Education (8,401) are close behind, so demand is spread fairly evenly across industries.
- Business Analyst has the most openings (8,940), followed by Machine Learning Engineer (8,767), Data Scientist (8,659) and Data Analyst (8,632). Data Engineer has the fewest (8,288).
- AI Engineer (₹1,39,945) and Machine Learning Engineer (₹1,39,705) have the highest average salaries, about 40% higher than Data Analyst (₹99,138), Data Scientist (₹99,646) and Data Engineer (₹98,711).
- Cloud is the most in-demand skill (5,291 postings), followed by Machine Learning (5,254) and Deep Learning (5,152). SQL has the lowest count of the skills shown (5,101).
- Remote jobs are slightly ahead of on-site jobs, at 51% versus 48%.
- Yearly openings stay steady between 7,300 and 7,500, peaking in 2021 (7,480) and dipping in 2024 (7,319).
